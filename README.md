# 印刷拼版系统

纯前端单页应用（无构建、无依赖），直接在浏览器打开 `index.html` 即可使用。
核心排版引擎 `js/engine.js` 为纯函数，可在 Node 下单测。

## 运行

- 使用：浏览器直接打开 `index.html`（或 `python3 -m http.server` 后访问）。
- 测试：`node test/engine.test.js`（15 项，覆盖规则 1–7）。

## 功能与需求对照

1. **固定摆版范围**：顶部设置纸张幅面、咬口宽、出血边。
   摆版可用区 = 四周让出出血边、底部再让出咬口（`engine.usableArea` / `gripperRect`）。
   画纸上青色虚线框为出血带，灰色实线框为可用区，底部橙色斜纹条为咬口。
2. **拖动即重排**：拖起任意成品件（画纸或左侧列表均可拖），其余件实时按
   shelf（水平条带）算法重排；当前纸张装满自动续到后面的纸张。
   拖拽监听挂在 document 上，渲染重建节点不会中断拖拽。
3. **按开数顺序续排，同件不重复**：新件按开数（全/对开/4开…）排序插入；
   `autoPack` 逐张逐行装箱，每件在结果中恰好出现一次，摆不下顺序续到下一张。
4. **落版三要素**：成品宽高、开数、留边缺一项时"加入拼版"按钮禁用并红字提示；
   留边计入占地（占地 = 成品尺寸 + 两侧留边），见 `engine.pieceReady / cellSize`。
5. **溢出当场标出**：松手时若件越出可用区（压出血带或超幅面），该件立即标红，
   标注原因（超幅面/出血）；本身大于可用区的件挂到末尾"溢出纸"，任何纸都不接收。
6. **咬口不可压**：件与咬口条相交即带 `gripper` 标记，所在纸张标红、
   纸签显示 ✗、标题提示"本张不算数"；拖回可用区即恢复有效。
7. **断点续摆**：所有状态（配置、成品件、排序、违规位置、当前纸张、缩放）
   实时写入 `localStorage`；拖动开始即记录 `dragDraft`，切走/关页面/刷新后
   回到原来那张未摆完的纸并显示续摆提示。

## 操作说明

- 左侧填表新增成品件：选开数会预填大度纸参考成品尺寸（可手改）。
- 拖动画纸上的件：绿色虚线框是松手后的槽位；红色框表示违规（压出血/咬口）。
- 拖到顶部纸签：把件追加到指定纸张末尾，纸满自动续排。
- 件右上角 ⟳ 旋转 90°（顶部可关闭"允许自动旋转"）。
- 顶部修改幅面/咬口/出血后，全部纸张按新约束即时重算。
- "清空"会删除全部成品件与进度。

## 文件

- `index.html` / `style.css`：界面与样式。
- `js/engine.js`：约束计算、开数排序、shelf 排页、溢出/咬口判定（纯逻辑）。
- `js/app.js`：状态、localStorage 持久化、画布渲染、拖拽交互。
- `test/engine.test.js`：规则单测。
